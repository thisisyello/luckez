# Luckez

로또 번호를 간단하게 랜덤 추첨하고, 역대 당첨번호를 확인할 수 있는 Flutter 앱입니다.

예전에 만들던 로또 번호 생성 앱을 다시 이어서 정리하고 개선하는 프로젝트입니다. 현재는 앱 구조, 화면 분리, 코드 정리, UI 개선을 단계적으로 진행하고 있습니다.

## 주요 기능

- 1부터 45까지의 숫자 중 중복 없는 6개 번호 랜덤 추첨
- 추첨된 번호 오름차순 정렬
- 번호 구간별 색상 표시
- 역대 당첨번호 목록 조회
- 라이트/다크 모드 전환

## 기술 스택

- Flutter
- Dart

## 프로젝트 구조

```text
lib/
  main.dart
  data/
  pages/
  widgets/
  theme/
```

## 진행 중인 작업

- 메인 추첨 화면 정리
- 역대 당첨번호 화면 분리
- 공통 위젯 분리
- 색상/theme 구조 정리
- 테스트 코드 갱신
